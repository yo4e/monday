# PURPOSE FIRST / Monday

AIに「あなたはプロのコンサルタントです」と名札を渡す代わりに、目的、相手、成功条件、本当に存在する制約を渡すためのブラウザツールです。

このリポジトリは、月野テンプレクス（Monday）がGitHub連携を試した最初期の小さなサンドボックスから始まりました。初代サイトを記念として `archive/first-sandbox/` に保存し、第二実験として全面的に作り直しています。

## できること

- 目的中心の共同制作ブリーフをリアルタイム生成
- AIへ渡す探索権限を0〜100で調整
- 旅行、ハッカソン、小説のサンプルを読み込み
- ブリーフをコピーまたはテキスト保存
- 入力内容をブラウザの `localStorage` に自動保存
- API、アカウント、外部送信、ビルド工程なし

## 設計原則

1. 人間は目的、文脈、好み、責任を持つ
2. AIには構造、探索、比較、実装を遠くまで走らせる
3. 初稿を見て、人間が「こうじゃない」を言語化する
4. 服従と精密化は二稿目から行う
5. 制約は予算、期限、環境、法務など現実に存在するものだけを書く

## ローカルで動かす

ES Modulesを使うため、任意の静的サーバーで配信してください。

```bash
python3 -m http.server 8000
```

その後 `http://localhost:8000` を開きます。

## 品質チェック

依存パッケージはありません。Node.js 20以上で実行できます。

```bash
npm run ci
```

- JavaScriptの構文確認
- HTML内のローカル参照と必須アクセシビリティ要素の確認
- `node:test` によるブリーフ生成ロジックのテスト

## 構成

```text
.
├── index.html                 # アプリ本体
├── style.css                  # 高コントラストのレスポンシブUI
├── app.js                     # DOM、保存、コピー、ダウンロード
├── brief.js                   # 副作用のないブリーフ生成ロジック
├── tests/                     # Node標準テスト
├── scripts/                   # リポジトリ整合性チェック
├── archive/first-sandbox/     # 連携初期の記念版
└── .github/workflows/         # CIとGitHub Pages
```

## プライバシー

入力内容はブラウザ内で処理し、同じブラウザの `localStorage` にのみ保存します。サーバー送信、解析タグ、広告、Cookieはありません。

## アクセシビリティ

- セマンティックHTMLと明示的なラベル
- キーボードフォーカス表示
- ライブリージョンによる操作結果通知
- `prefers-reduced-motion` 対応
- モバイル表示対応
